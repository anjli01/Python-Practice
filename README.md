# Python-Practice

A structured repository for Python programming, from core language foundations and intermediate mastery to full algorithmic problem-solving with the NeetCode 150 library.

---

## 📂 Repository Contents

### 1. [Python Basics](Python%20Basics/)
Interactive Jupyter notebooks covering Python essentials:
- `0_basics.ipynb` – Syntax, variables, data types, and basic I/O
- `1_foundations.ipynb` – Core operations, type conversion, and operators
- `2_strings.ipynb` – String manipulation, slicing, and formatting
- `3_control_flow.ipynb` – Conditionals, loops, and comprehensions
- `4_lists_tuples.ipynb` – Sequences, indexing, and slicing
- `5_dicts_sets.ipynb` – Hash maps, key-value operations, set logic
- `6_functions.ipynb` – Arguments, return values, scope, and lambdas
- `7_files_errors.ipynb` – File handling, exception management

### 2. [Python Intermediate](Python%20Intermediate/)
Intermediate-to-advanced Python concepts:
- `1_oop_foundations.ipynb` – Classes, objects, attributes, and methods
- `2_oop_advanced.ipynb` – Inheritance, polymorphism, and encapsulation
- `3_iterators_generators.ipynb` – Iterators, generator expressions, and `yield`
- `4_decorators_closures.ipynb` – Function decorators, closures, and wrappers
- `5_regex.ipynb` – Regular expressions and pattern matching
- `6_errors_context.ipynb` – Context managers (`with` statements) and custom exceptions
- `7_testing_capstone.ipynb` – Unit testing and integration capstone

### 3. [NeetCode 150](NeetCode150/)
Complete, verified implementations of all **150 / 150 NeetCode problems** across **18 categories**:
- 📚 **18 In-Depth Study Guides** covering core concepts, patterns, interview tips & tricks, and embedded video solution links
- 💡 **Optimal Solutions** with clean Python 3 implementations and time/space complexity analyses
- 🎥 **100% Video Coverage** with verified YouTube solution links for all 150 problems (`python NeetCode150/verify_video_links.py`)
- 🧪 **Comprehensive Automated Unit Tests** with edge cases
- 🏆 **Master Verification Runner** (`python NeetCode150/verify_all_150.py`) verifying all 150 problems
